# Sognu
### Sognu by Lumera Games

Lumera,  un village de montagne en Corse, dans les années 90.
Le jour, c’est le monde réel : le comptoir, les habitués, les confidences, les rumeurs.
La nuit, c’est le monde du rêve : un maquis sombre et déformé, où se déroulent d’étranges chasses.

### Touches:

Mouvement: Flèches
Interagir: E
Quitter: CTRL + X
